# dft-course

A personal, self-paced course in **Density Functional Theory**: from rusty undergrad quantum mechanics to PhD-level practice, with a focus on running real calculations.

## Workspace layout

| Path | Purpose |
|---|---|
| `MISSION.md` | Why I'm learning DFT and what success looks like *(coming next)* |
| `RESOURCES.md` | Curated, trusted textbooks, papers, docs and communities *(coming)* |
| `NOTES.md` | Teaching preferences (visual, calculation-first) |
| `learning-records/` | What has been learned/established, used to pick the next lesson |
| `lessons/` | Short illustrated HTML lessons with quizzes |
| `reference/` | Cheat sheets and glossary for quick lookup |
| `assets/` | Shared styles and interactive widgets used by lessons |
