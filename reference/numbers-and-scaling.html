Key formulas

n(r) = N ∫ |ψ(r, r2, …, rN)|² dr2 … drN     ∫ n(r) dr = N

Handy conversions

  • 1 double-precision number = 8 bytes; a complex number = 16 bytes
  • 16 GB of RAM ≈ 2 × 109 real numbers
  • Atoms in the observable universe ≈ 1080 (standard rough estimate)

Rules of thumb

  • The exponential wall (Kohn): the cost of storing ψ is multiplied by M3 for every added electron.
  • DFT's move: work with n(r), which is 3D for any number of electrons.
